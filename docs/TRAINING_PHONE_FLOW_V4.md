# 실전 문자 훈련: 휴대전화 기능 패널 v4

## 설계 원칙

사용자가 상대의 문자를 읽고 **직접 행동을 찾아 선택하는 훈련**이다. 첫 메시지 아래에 '정답 행동' 버튼을 제시하지 않는다. 현실에서는 첫 메시지만으로 확인이 필요한 경우도 있으므로, 기능을 사용하기 위한 최소 턴 수를 강제하지 않는다. 대신 **외부 확인 행동이 곧 훈련 종료가 되지 않도록** 대화와 행동을 분리한다.

## 진입과 주목 효과

- 상단 오른쪽의 휴대전화 아이콘에서 언제든지 모의 기기를 열 수 있다. 첫 화면은 연락처, 전화, 앱, 메시지 네 기능이며 '공식 경로 확인'을 직접 노출하지 않는다.
- 사용자가 '번호·전화·연락처·앱·확인' 의사를 텍스트로 표현하거나, 사용자 답장이 두 번 오간 뒤 **한 번만** 1.9초 동안 테두리·배경이 아주 약하게 변한다.
- 정상/사칭 여부, 위협 문구, AI 행동 요청의 종류에 따라 강조를 차등 표시하지 않는다. 강조는 위험 경보나 정답 힌트가 아니다.
- 움직임 감소 설정에서는 애니메이션 대신 정적인 약한 강조를 제공한다. 화면을 가리는 큰 안내 말풍선은 제거한다.

## 모의 휴대전화 선택

| 화면 | 항목 | 서버 행동 | 효과 |
| --- | --- | --- | --- |
| 연락처 | 저장된 가족 연락처 | `family_contact` + `saved_family` | 가족 관련 상황에서는 확인, 다른 상황에서는 단순 상담 |
| 연락처/전화 | 현재 문자 발신자·최근 번호 | `verify_sender` + `recent_sender` | 발신자의 주장만 확인; 독립 신원 확인이 아님 |
| 전화 | 직접 찾은 기관 대표번호 | `verify` + `official_directory` | 택배/은행 상황의 독립 확인 |
| 설치된 앱 | 은행 앱 또는 택배 앱 | `verify` + `bank_app`/`delivery_app` | 해당 상황에 일치할 때만 독립 확인, 관련 없는 앱은 로컬 안내만 |
| 메시지 | 대화 복귀 | 없음 | 아무 판정이나 행동 기록 없이 문자 화면으로 복귀 |

- 모의 전화/앱 실행 결과는 패널에서 확인하고 문자로 돌아올 수 있다. **독립 확인, 가족 연락, 발신번호 전화는 대화를 닫지 않는다.**
- 송금·개인정보 제출, 사용자의 명시적인 대화 중단, AI의 자연 종료, 최대 8턴 도달은 이전대로 종료 가능하다.
- 행동 요청을 따른 링크·송금·정보 제공은 기존 메시지별 봉인된 `actionId` 검증을 유지한다.
- 서버는 휴대전화 행동의 `method`를 시나리오에 대조하고 재사용이나 출처 위조를 거부한다. 직접 `verify`만 전송해 결과를 얻는 단축 호출을 허용하지 않는다.
- 대화 완료 시, 실제 위험 요청이 나왔는지와 초기 종료 여부를 구분한다. 대응을 관찰하지 않은 경우에는 평가의 범위를 사용자에게 알려준다. 조기에 외부 확인을 한 것 자체를 잘못된 행동으로 평가하지 않는다.

## 검증 및 제약

- 자동 테스트: 정상/사칭 6개 상황에서 경로별 확인, 최근 발신번호의 미확인 판정, 메서드 위조/중복 거절, 초기 확인 비종료, 이른 종료 시 한정된 피드백, UI 연결·접근성 관련 정적 단언.
- 실제 통화, 문자 수신, 앱 실행, 금융정보 입력은 하지 않는다. 모든 장면은 웹 내부의 모의 화면으로 동작한다.
- CI 테스트는 실제 LLM이 5~8턴 동안 충분히 자연스럽게 진행되는지, 화면의 체감 품질·응답속도를 보증하지 않는다. 실사용 검수는 별도로 필요하다.
